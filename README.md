# RAGE MP · Авторизация и регистрация

![RAGE MP · Авторизация и регистрация — превью](preview.jpg)

Архивная работа для **RAGE MP**. Интерфейс опубликован для знакомства с моими ранними проектами.

[Открыть демо](https://xtrasupra.github.io/ragemp-auth-ui/) · [Исходный код](https://github.com/xtrasupra/ragemp-auth-ui)

## О проекте

Это моя ранняя работа для RAGE MP, сохранённая как часть истории развития навыков разработки игровых интерфейсов. В оформлении и сценариях взаимодействия отражён подход, с которым я работал на этом этапе.

## Возможности

- Авторизация, регистрация и восстановление доступа в едином интерфейсе.
- Поля ввода с иконками, переключение экранов и согласие с правилами.
- Тёмная палитра с лаймовыми акцентами и авторская компоновка.

## Запуск

Требуется Node.js 22.12+ или 24+.

```bash
npm ci
npm run dev
```

`npm run build` создаёт готовый сайт в `docs/`. GitHub Pages публикует эту папку из ветки `main`. Пути ресурсов относительные, поэтому демо работает и в подпапке репозитория.

## Демонстрационный режим

Сайт позволяет познакомиться с внешним видом и локальными состояниями интерфейса. Игровые действия требуют клиента и сервера RAGE MP. Браузерная обвязка показывает уведомление о выборе действия; она не подключается к серверу, не сохраняет и не отправляет введённые данные. Небольшая кнопка ↻ в правом верхнем углу возвращает экран в исходное состояние.

## Подготовка архива

Для самостоятельного запуска добавлены точка входа, Vite и браузерная обвязка. Служебные файлы и дубли архивов исключены; исходная визуальная концепция сохранена.

## Экраны компьютеров

Сохранена исходная настольная композиция. Интерфейс масштабируется целиком относительно 1920×1080 с учётом ширины и высоты окна. Переключение вкладок не меняет масштаб; боковые панели и вложенные меню остаются в одной системе координат.
